Proyectos destacados

DuckyWare — Aplicación Web Backend

Aplicación web de comercio electrónico completamente funcional desarrollada con Python y Django. El proyecto incluye autenticación de usuarios y roles, gestión de productos y stock, procesamiento de pedidos e integración de pagos. Además, dispone de una interfaz administrativa para la gestión de la tienda y del personal.

Tecnologías: Python, Django, SQL, HTML, CSS, JavaScript

OnlineStore — Aplicación de Escritorio (JavaFX)

Aplicación de escritorio desarrollada en Java utilizando JavaFX, diseñada siguiendo una arquitectura MVC limpia. El proyecto implementa patrones DAO y ORM para la persistencia de datos y pone el foco en la mantenibilidad, escalabilidad y separación de responsabilidades en un contexto académico real.

Tecnologías: Java, JavaFX, ORM, DAO, MVC
